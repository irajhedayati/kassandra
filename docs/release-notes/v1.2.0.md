# Kassandra v1.2.0 release notes

Released 2026-09-22.

## Highlights

- **Import connection profiles.** **Manage connections** gets an **Import configuration** dialog. Drop or browse for a JSON file, or paste JSON. It accepts a single profile, an array, or an object with a `connections` array, and reports which profiles imported.
- **Reconnect.** A **Reconnect** button next to Disconnect re-establishes the current connection, for example after credentials change. The profile list is now a searchable select.
- **Richer map schemas.** Map schema entries have a label and a value type (text, JSON, enum or a scalar CQL type), and the forms render each key with the matching editor. Known keys from Table Info pre-populate `map<text, text>` entries, and saves are confirmed before the dialog closes.

## Fixes

- The generated INSERT includes `uuid()` for blank UUID key columns.
- Saving a map schema entry's label works.
- Row details update when you select a different row.
- Fixed type errors after the Express 5 and React 19 upgrades.

## Quality and docs

- Unit tests for the shared type helpers, the CQL builders, and the row repository.
- Refreshed README with a feature table, tagline, branding and demo GIF, and updated documentation.

## Dependencies

- Major upgrades: React 18 to 19, Express 4 to 5, Vite 5 to 8, Tailwind CSS 3 to 4, TypeScript 5.9 to 7, zod 3 to 4, TanStack Table 8 to 9, `@vitejs/plugin-react` 4 to 6, and Node 26.
- Also updated: `monaco-editor` 0.55 to 0.56, `uuid` 11 to 14, TanStack Query, and `concurrently`.
