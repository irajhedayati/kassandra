# Kassandra v1.1.0 release notes

Released 2026-09-04.

## Highlights

- **Datacenter selection.** Connection profiles have an optional local datacenter, so the driver prefers nodes in that datacenter and falls back to others only if it becomes unreachable (closes #9).
- **Review before you run.** The insert and update forms now send their statement to the CQL editor instead of running it. Updates are minimal: only the fields you changed appear in the generated `UPDATE`.
- **Favorite keyspaces.** Star a keyspace in the top bar. Favorites are saved per connection profile and listed first.

## Data and forms

- Enum fields: mark a text column as `enum` in Table Info and edit it with a dropdown of allowed values.
- JSON syntax highlighting for text columns marked as JSON.
- Row details open in an inline panel under the grid instead of a modal.
- A refresh button on the data grid.
- Cancel buttons on the forms, and fixes for editing map entries.
- The data browser's filters are limited to partition and clustering key columns.

## UI

- The CQL editor is collapsible.
- The table list is searchable, and the searchable dropdowns support keyboard navigation and a clear button.

## Build

- CI and the runtime move to Node 24.
- GitHub Actions dependency updates (`actions/checkout`, `actions/setup-node`).
