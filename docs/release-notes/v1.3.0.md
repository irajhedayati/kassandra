# Kassandra v1.3.0 release notes

## Highlights

- **Create keyspaces and tables from the UI.** A **+** button next to the Keyspace and Table dropdowns opens a guided dialog. Each dialog shows a live CQL preview and has a **?** help guide that links to the DataStax reference.
  - **Keyspace:**
    - SimpleStrategy or NetworkTopologyStrategy.
    - Replication factor, or replicas per datacenter with the cluster's known datacenters suggested.
    - Durable writes and IF NOT EXISTS.
  - **Table:**
    - Columns with partition keys, clustering keys (ASC/DESC) and static columns.
    - List, set and map types, with a `frozen` option.
    - Options for comment, default TTL, GC grace, compaction and compression.
    - The preview flags invalid definitions, such as a missing partition key or an unfrozen collection in a key, before you run anything.

  ![Creating a keyspace](https://raw.githubusercontent.com/irajhedayati/kassandra/main/docs/images/create-keyspace.gif)

  ![Creating a table](https://raw.githubusercontent.com/irajhedayati/kassandra/main/docs/images/create-table.gif)

- **Stop a connection attempt.** While connecting or reconnecting, the button becomes a spinning **Stop**. It aborts the request and cancels the pending driver connection on the server, so a stopped attempt never becomes the active session.
- **Execution time and duration in the CQL editor.** After each run, a status line under the results shows when the query was sent and how long it took.

## Map columns

- **Add entry** opens a searchable dropdown of the keys defined in the map schema. Choosing a key switches the value field to that key's type (text, JSON, enum, number, date/time, checkbox and so on).
- Custom keys still work: type one and choose "Use … as a custom key".
- Defined keys are no longer pre-filled into every new or empty map.
- The Data Browser can filter map columns by key, by value, or by key = value.

## UI polish

- Enum fields, the Table Info type picker, the map schema type picker and the new dialogs use the same dropdown as the grid filters, with optional search for long lists.
- That dropdown renders above the page, so it is no longer clipped inside scrolling tables or dialogs.
- Added a proper favicon in place of the 900 KB logo.

## Fixes and under the hood

- **Map and set values** were being bound as empty collections because the driver wasn't told to use ES6 `Map`/`Set`. It is now configured to.
- The row API now converts form text to the right driver type per column (numbers, uuid, timestamp, blob and so on) and generates blank uuid/timeuuid keys. The insert and update forms still generate CQL for you to run, as before.
- Data Browser filters are type-aware, so equality filters on non-text columns use properly typed values.
- Added about 20 new tests, including the shared CREATE TABLE builder.
