# Kassandra v1.0.0 release notes

First release of the Node.js and React rewrite (tagged 2026-06-16). The previous Python/Streamlit app was renamed from py-sandra to **Kassandra**, moved to [`legacy/`](../../legacy) for reference, and replaced.

## Highlights

- **New stack.** An Express and `cassandra-driver` server written in TypeScript, and a React, Vite and Tailwind client. Both share types from a common `shared` package. One process serves the API and the built app on a single port.
- **Feature parity with the Python app.** Connection profiles, schema browsing, the data browser with pagination, schema-driven insert and update forms, row deletion, the CQL editor, and per-column metadata (hidden columns, JSON and enum display, map schemas).
- **Prepared statements everywhere.** All row operations bind parameters. The Python app built the UPDATE statement by string interpolation, which was a SQL-injection risk.
- **New look.** A TailAdmin-flavoured theme and the Kassandra branding.

## Fixes

- Connecting no longer fails with `protocolOptions.maxVersion provided (5) is invalid`.
- TLS connections skip the hostname check, so you can connect through tunnels or NAT when the address isn't in the certificate.
- Python app, before the rewrite: fixed INSERT, and fixed enabling **Edit Map Schema**.

## Build and CI

- GitHub Actions updated for the Node and React rewrite.
- The Docker build works on public CI runners.
- Dependency updates for the Python app and the GitHub Actions used by CI.
